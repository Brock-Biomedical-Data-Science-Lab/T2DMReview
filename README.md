# T2DMReview
This repository contains the processed files and selected analysis scripts for the paper:

“Cheminformatics of Diabetic Protein Targets and Therapeutics.” (Zhao et al.)

## Directory Structure
```text
data/
├── Boltz-2 inputs/
│   └── ...                    # Input files used for Boltz-2 prediction
│
├── abcc8/
│   ├── protein/
│   │   ├── <protein>.pdbqt    # Prepared protein structure used as the AutoDock Vina receptor
│   │   ├── calc_docking_box.py
│   │   ├── config.txt         # AutoDock Vina docking-box configuration
│   │   └── pdb_files/
│   │       ├── <protein>_raw.pdb
│   │       ├── <protein>_remove_water.pdb
│   │       └── <protein>_clean.pdb
│   └── <drug>/
│       ├── <drug>.smi         # SMILES input for the ligand
│       ├── <drug>.pdb         # Prepared 3D ligand structure
│       ├── <drug>.pdbqt       # Prepared ligand input for AutoDock Vina
│       ├── <drug>_out.pdbqt   # AutoDock Vina docking output containing ligand poses
│       ├── complex/            # Protein–ligand complexes generated by combining each Vina pose with the receptor
│       └── closest/            # PLIP results for the representative pose selected in the manuscript
│
├── dpp4/
│   ├── protein/
│   └── <drug>/
│       └── ...
│
├── pparγ/
│   ├── protein/
│   └── <drug>/
│       └── ...
│
└── sglt2/
    ├── protein/
    └── <drug>/
        └── ...
```
